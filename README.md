# claude

Marketplace de plugins para Claude Code.

## Plugins

- [`multi-model`](plugins/multi-model/) — Equipo de subagentes: Sonnet lee código, planifica y documenta; Opus diseña y desarrolla frontend y backend; Haiku ejecuta comandos básicos y sube a git. Trabajan en paralelo.

## Instalación

```
/plugin marketplace add ChemaSanchez11/claude
/plugin install multi-model@chemasanchez-plugins
```
